Sphere on a slope¶

A free sphere falls on a Mohr-Coulomb slope standing in a box of 5 planes. The slope, the planes and the sphere are read from Blender files. Port of mpmxdem's sphereOnSlope.sim.

# mpmxdem mpm/3D/Examples/sphereOnSlope.sim: a free sphere on a Mohr-Coulomb slope standing in a box. SI units.
# Needs the Blender files of the original example in the run directory (not in mpmxdem; small synthetic ones in
# example/blender are used by the tests):
# coordMP.txt (slope), coordPlanes0..4.txt (box) and coordSpheres.txt (sphere).

configuration:
  nogpu: true

global:
  dt: 1.0e-5
  simulation_end_iteration: 299999   # mpmxdem: nstep 300000
  mpm_vtk_period: 2000

input_data:
  - parameters:
      gravity: [ 0.0 , -9.81 , 0.0 ]
  # mpmxdem new_set_grid 13 7 6 0.25: 52 x 28 x 24 elements of 0.25 m
  - domain:
      cell_size: 0.25
      grid_dims: [ 53 , 29 , 25 ]
      bounds: [ [ -0.125 , -0.125 , -0.125 ] , [ 13.125 , 7.125 , 6.125 ] ]
      periodic: [ false , false , false ]
      expandable: false
  - grid_flavor_mpm
  - init_rcb_grid
  - blender_set_mp_grid: { group: 0, density: 2000., file: coordMP.txt, size: 0.125 }
  - obstacles:
      obstacles: [ "Plane2 0 coordPlanes0.txt", "Plane2 0 coordPlanes1.txt", "Plane2 0 coordPlanes2.txt",
                   "Plane2 0 coordPlanes3.txt", "Plane2 0 coordPlanes4.txt",
                   "Sphere2 1 coordSpheres.txt free 2700.0 0.0 0.0 0.0 0.0" ]
  - contact_laws:
      set: [ "mu 0 0 0.3", "kn 0 0 1.0e6", "en2 0 0 1.0", "kt 0 0 0.5e6",
             "mu 0 1 0.3", "kn 0 1 1.0e6", "en2 0 1 1.0", "kt 0 1 0.5e6" ]

init_epilog: mpm_init
compute_loop: mpm_compute_loop

mpm_constitutive_model:
  - mohr_coulomb: { group: 0, young: 70.0e6, poisson: 0.42, friction_angle: 0.5, cohesion: 1.0e3, dilatancy_angle: 0.05 }

Input files¶

The deck reads coordMP.txt (slope, see coordinate files), coordPlanes0..4.txt (box) and coordSpheres.txt (sphere) from the run directory.

The Blender files of the original example are not distributed with mpmxdem. The exaMPM repository provides small hand-written files in example/blender/ (a 8 × 4 × 3 m slope, a box and a sphere of radius 0.4 m), used by the test:

1
2
mkdir run && cp ${EXAMPM_SRC_DIR}/example/blender/* run/ && cd run
exaMPM ${EXAMPM_SRC_DIR}/example/sphere_on_slope.msp --set-global-simulation_end_iteration 1999

Validation¶

With the files of example/blender/ and legacy_plane: true, exaMPM and mpmxdem create the same 36864 material points; after 2000 steps their positions differ by less than \(6 \times 10^{-6}\) m and the sphere trajectories by about \(10^{-6}\) m.

# Getting Started

`exaMPM` has no `main()` that you edit and no fixed input format: a simulation is a **graph of operators**
described in YAML. These pages explain the three ideas you need before writing a deck:

- [**Building blocks**](building_blocks.md) — operators, slots and batches
- [**Configuration files**](configuration_files.md) — the default configuration and how a deck overrides it
- [**YAML basics**](yaml_basics.md) — the YAML syntax and the onika extensions used in `.msp` files
